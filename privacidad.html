Política de privacidad de Publicador Sin Tutorial

Última actualización: 19 de noviembre de 2026

Publicador Sin Tutorial es una herramienta de uso personal del titular del canal de YouTube Sin Tutorial (w.hugocosta@gmail.com). No tiene otros usuarios.

Datos a los que accede

Con autorización OAuth del propio titular:

  • YouTube: subir vídeos al canal Sin Tutorial y consultar el estado de esos vídeos.
  • Google Drive: leer los archivos de vídeo de una única carpeta del titular.

Uso de los datos

Solo para subir y programar los Shorts del canal. No se venden, no se comparten con terceros y no se usan para publicidad.

Almacenamiento

Las credenciales de acceso se guardan cifradas como secretos de un repositorio privado de GitHub. Los vídeos se descargan temporalmente para subirlos y se eliminan al terminar cada ejecución.

Revocar el acceso

En myaccount.google.com/permissions, eliminando «Publicador Sin Tutorial».

El uso de los datos de las API de Google cumple la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.
