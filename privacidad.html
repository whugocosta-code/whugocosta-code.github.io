Política de privacidad de Publicador Sin Tutorial

Última actualización: 20 de noviembre de 2026

Publicador Sin Tutorial es una herramienta de uso personal del titular del canal de YouTube Sin Tutorial (w.hugocosta@gmail.com). No tiene otros usuarios.

Servicios de API de YouTube

Publicador Sin Tutorial usa los Servicios de API de YouTube. Al usarlo, aceptas los Términos del Servicio de YouTube. Los datos que se obtienen a través de YouTube también se rigen por la Política de Privacidad de Google.

Datos a los que accede

Con autorización OAuth del propio titular:

  • YouTube: subir vídeos al canal Sin Tutorial y consultar el estado de esos vídeos (ID del vídeo, estado de privacidad y fecha de publicación programada).
  • Google Drive: leer los archivos de vídeo y de texto de una única carpeta del titular.

Uso de los datos

Solo para subir y programar los Shorts del canal y comprobar si se han publicado. No se venden, no se comparten con terceros, no se usan para publicidad y no se muestran a nadie fuera del titular.

Almacenamiento

Las credenciales de acceso se guardan cifradas como secretos de un repositorio privado de GitHub. Se conserva un registro privado con el ID de cada vídeo subido, su hora programada y su estado. Los archivos de vídeo se descargan temporalmente para subirlos y se eliminan al terminar cada ejecución. No se usan cookies.

Eliminación de datos

El titular puede pedir la eliminación de los datos guardados escribiendo a w.hugocosta@gmail.com. Los datos guardados (credenciales y registro) se eliminan en un plazo máximo de 7 días desde la solicitud o desde la revocación del acceso. Los datos obtenidos de la API de YouTube no se conservan más de 30 días sin actualizarse.

Revocar el acceso

Se puede revocar el acceso en cualquier momento desde la página de permisos de seguridad de Google: https://security.google.com/settings/security/permissions, eliminando «Publicador Sin Tutorial».

El uso de los datos de las API de Google cumple la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.
